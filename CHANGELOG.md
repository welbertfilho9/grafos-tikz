# Changelog

## [1.0.0] — 2025

### Adicionado
- Editor visual de grafos com SVG interativo
- Ferramentas: Mover, Selecionar, Multi-seleção, Vértice, Aresta, Laço, Subdivisão, Deletar
- Laços arrastáveis (girar direção com drag)
- Arestas paralelas com espaçamento automático
- Geradores: Kₙ, Cₙ, Pₙ, Kₘₙ, Bₙ, Wₙ, Qₙ, Complemento, Produto Cartesiano
- Análise: vértices de corte, pontes, blocos biconexos (Tarjan)
- Exportação TikZ compatível com `arrows,shapes,snakes`
- Undo/Redo (60 estados), Auto-layout force-directed
- Contador global via Supabase
- Google Analytics 4
- Salvar/Carregar JSON
