📖 Ajuda — Gerador de Grafos em TikZ

Crie grafos visualmente e exporte código TikZ pronto para o Overleaf

🛠 Ferramentas
⊙ SelecionarClique para selecionar um elemento. Arraste vértices para mover.
⬚ MultiArraste para criar caixa de seleção. Selecione vários ao mesmo tempo.
● VérticeClique em qualquer ponto do canvas para criar um vértice.
— ArestaClique no vértice de origem, depois no destino. Clique no mesmo vértice duas vezes para criar laço.
↺ LaçoClique em um vértice para adicionar um laço (loop) nele.
⊕ SubdivisãoClique em uma aresta para inserir um novo vértice de grau 2 no meio.
✕ DeletarClique em qualquer elemento para removê-lo.
⚡ Geradores Automáticos
Kn — Grafo completo com n vértices (todos conectados entre si)
Cn — Ciclo com n vértices
Pn — Caminho com n vértices
Km,n — Grafo bipartido completo com partições de tamanho m e n
Bn — Buquê de n círculos (1 vértice com n laços)
Wn — Roda (Wheel) com n raios + hub central
Qn — Hipercubo n-dimensional (Q₁=K₂, Q₂=C₄, Q₃=cubo)
Ḡ Compl. — Complemento do grafo atual (inverte as arestas)
□ Prod. Cart. — Produto cartesiano G□G₂ com um segundo grafo escolhido
🔬 Análise do Grafo
Clique em 🔬 Analisar para calcular automaticamente:
• Vértices de corte (destacados em vermelho tracejado no grafo)
• Pontes/bridges (destacadas em laranja)
• Blocos biconexos (cada bloco em uma cor diferente)
• Grau máximo Δ, mínimo δ, médio, sequência de graus
• Se é Euleriano, Semi-euleriano, Bipartido, Regular
• Diâmetro, raio, número de componentes conexas
Clique novamente em 🔬 Analisar para desativar e limpar os destaques.
🎨 Exportação TikZ
O painel direito gera código TikZ em tempo real.
• Escala TikZ: controla o tamanho da figura no documento LaTeX
• Caption e Label: preenchidos diretamente pelo app
• Posição: H, h, t, b, p do float figure
• Estilo dos nós: padrão, preenchido, branco, mínimo ou ponto
• Cores customizadas são exportadas como \definecolor
• Botão ⬇ .tex baixa o arquivo diretamente
